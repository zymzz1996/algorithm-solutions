BM1(反转链表):两个指针pre和cur，pre开始指向null，cur指向head，循环条件cur不等于null，循环体cur指向pre，cur和pre向后移
BM2(链表内指定区间翻转):新加表头，两个指针pre和cur，cur先遍历到m位置，再从m位置遍历到n位置，过程中每次将cur后一个节点移到cur前面，pre后面
BM3(链表中的节点每k个一组翻转):递归，先判断元素数量不够k个直接返回，两个指针pre和cur，开始反转，直到cur指向下一段表头后递归调用，pre是反转后的表头，head是表尾
BM4(合并两个排序的链表):新建哑节点，cur指向当前节点，遍历head1和head2并比较大小，移动cur和head1或者head2
BM6(链表中环的检测):快慢指针fast和slow，慢指针每次走一步，快指针每次走两步，如果重合则有环否则没环
BM7(链表中环的入口节点):哈希/快慢指针fast和slow，先检测有环，可知相遇点到入口和表头到入口的距离相等，此时两个指针分别从相遇处和表头同样速度遍历，相同节点即为入口
BM8(链表中倒数最后k个节点):快慢指针，快指针先走k步，然后快慢指针同时向后走，当快指针指向null的时候，慢指针所指即为倒数第K个节点
BM9(删除链表的倒数第n个节点):新加哑节点，pre指向哑节点，cur指向head，fast指针向后遍历n次，然后三个指针同时遍历，当fast指向null的时候，删除cur即可
BM10(两个链表的第一个公共节点):两个指针l1和l2，当l1不等于l2时，向后遍历，直到为null时指向另一个链表表头
BM11(链表相加(二)):(1)利用辅助栈，栈顶弹出相加，再加进位，进位=和/10，当前值=和%10(2)反转链表后再相加
BM12(单链表的排序):(1)辅助数组或集合，数组排序后再转为链表(2)归并排序
BM13(判断链表是不是回文结构):辅助数组+双指针
BM14(链表的奇偶重排):双指针，向后遍历，最后将奇数位最后一个元素与偶数位第一个元素相连
BM15(删除有序链表中重复的元素-I):遍历删除，判断当前的值和next的是否相等
BM16(删除有序链表中重复的元素-II):(1)遍历比较删除(2)哈希表
BM17(二分查找-I):左右指针
BM18(二维数组中的查找):对于左下角元素，右侧元素比他大，上方元素比他小，所以从左下角元素开始遍历
BM19(寻找峰值):如果mid右侧的比mid大，则峰值在[mid+1,right]，否则峰值在[left,mid]
BM20(数组中的逆序对):归并排序(递归，先递归调用sort，再合并)，左右两个数组排序后判断，如果左边比右边大，则左边该元素后所有都比右边的元素大，例如[4,3] [2,1]
BM21(旋转数组的最小数字):二分后比较mid和right的大小，若mid>right，则left=mid+1，若mid<right，则right=mid，若mid=right，则right--
BM22(比较版本号):双指针往后遍历，.之间的字符串转为数字后比较大小
BM23(二叉树的前序遍历):先遍历根节点，再遍历左子树，再遍历右子树
BM24(二叉树的中序遍历):先遍历左子树，再遍历根节点，再遍历右子树，二叉搜索树中序遍历有序
BM25(二叉树的后序遍历):先遍历左子树，再遍历右子树，再遍历根节点
BM26(求二叉树的层序遍历):队列(ArrayDeque)存储每层的数据，每次弹出队列长度的元素，再添加这些元素的子节点到队列中
BM27(按之字形顺序打印二叉树):层序遍历的基础上，增加标识判断当前层的方向，如果需要则翻转数组
BM28(二叉树的最大深度):递归，返回左子树和右子树的深度的最大值+1，当节点为null则递归终止返回0
BM29(二叉树中和为某一值路径(一)):递归，当节点为null时返回false，当左节点为null且右节点为null且sum-cur.val=0时返回true，否则返回false，最终返回递归调用左子树结果 || 右子树结果
BM30(二叉搜索树和双向链表)：(1)中序遍历存储在数组中，再将数组转换为双向链表(2)在原树操作，维护两个指针，pre代表当前节点的前一个节点，然后将pre和当前节点建立双向后，pre指向当前节点，head指针指向链表表头
BM31(对称的二叉树):递归，当两个节点都为null是返回true，当其中一个不为null或者节点值不相等返回false，否则返回递归（左1，右2 && 右1，左2）
BM32(合并二叉树):递归合并，有一个节点为null则返回另一个，否则相加两个节点的值，递归合并左节点和右节点
BM33(二叉树的镜像):递归，当节点为null返回，将左右子树递归调用后的结果，反向赋值当前节点的左右指针
BM34(判断是不是二叉搜索树):中序遍历有序，pre指针指向前一个节点，当pre>cur.val返回false，否则当节点为null返回true
BM35(判断是不是完全二叉树):层序遍历，如果当前节点为null则到达叶子节点，后续再有节点返回false
BM36(判断是不是平衡二叉树):递归，当前节点为null返回true，计算左右子树高度，返回左子树是平衡二叉树且右子树是平衡二叉树且高度差小于等于1
BM37(二叉搜索树的最近公共祖先):(1)分别查找p和q并报错路径为数组，数组中最后一个相同值即为结果(2)递归，当前值在p和q之间或者q和p之间则为结果，否则若均小于p和q，则在右子树，否则在左子树
BM38(在二叉树中找到两个节点的最近公共祖先):深度优先搜索dfs+回溯，保存路径数组，路径数组中最后一个相同值即为结果
BM40(重建二叉树):递归，前序数组0索引元素是中序数组左子树和右子树的分割位，分割数组获得左右子树
BM41(输出二叉树的右视图):递归建树+层序遍历，层序遍历取该层最后一个元素
BM42(用两个栈实现队列):插入时直接插入栈1，弹出时如果栈2有元素则直接弹出，否则将栈1的元素弹出插入栈2，再从栈2弹出
BM43(包含min函数的栈):双栈法，栈1push的时候，栈2需要push当前的最小值，比如此时栈1 1,2,3，栈2 1,1,1，弹出时栈1和栈2都要弹出
BM44(有效括号序列):栈，遍历字符串，遇右括号与左括号做匹配，匹配不上返回false，或者当前栈已经空了返回false
BM46(最小的k个数):(1)Arrays.sort优化后的快速排序，时间复杂度o(nlog2k)(2)堆排序，时间复杂度o(nlog2k)
BM47(寻找第k大):快速排序，判断哨兵索引和k的和是否等于数组长度
BM48(数据流中的中位数):插入排序，集合调用add(i, num)
BM49(表达式求值):栈+递归，遍历字符串，对于+后的数字直接入栈，对于*后的数字弹出栈顶的数字相乘后入栈，对于括号内的表达式递归调用
BM50(两数之和):哈希表
BM51(数组中出现次数超过一半的数字):哈希表
BM52(数组中只出现一次的两个数字):哈希表
BM53(缺失的第一个正整数):哈希表保存数据，从1遍历查询哈希表，查到+1，直到查不到
BM54(三数之和):双指针，转化为两数之和，先排序，第一个数a小于0，则查找两数之和是-a的数，对于相邻的数字如果相同，需要去重
BM55(没有重复项数字的全排列):递归+回溯，linkedlist用于保存已经选择的元素，回溯时需要删除
BM56(有重复项数字的全排列):递归+回溯，此时不能使用linkedlist了，因为有重复元素，需要新建标识数组来保存当前索引位是否被选择，同时需要对原数组排序，用于判断前一个和当前元素相同时跳过，注意前一个和当前元素相同时，前一个元素一定是没有被选择的才能跳过
BM57(岛屿数量):递归+dfs，如果当前位置为'1'，则岛屿数量+1，同时向四个方向递归搜索，直到越界或者为'0'时终止，否则更新该位置为'0'
BM58(字符串的排列):递归+回溯，不能用linkedlist，需使用hashmap或者array标志，结果集也需要去重判断
BM59(括号生成):递归+回溯，选择右括号时，需要判断当前已选择的左括号的数量，即right<left时才能选择right，左右括号选择数量最大为n
BM60(矩阵最长递增路径):dfs，朝上下左右四个方向搜索，直到小于前一个值或者当前位置已经走过则终止
BM62(斐波那契数列):当n>=3时，dp[n] = dp[n-1] + dp[n-2]；当n=1,2时，dp[n] = 1
BM63(跳台阶):对于第n阶，只能从n-1阶或者n-2阶跳上来，dp[n]表示跳到第n阶时跳法数量，那么dp[n] = dp[n-1] + dp[n-2]，特别的dp[1]=1,dp[2]=2
BM64(最小花费爬楼梯):dp[n]表示爬到第n阶所需的最小花费，dp[n] = Min(dp[n-1] + cost[n-1], dp[n-2] + cost[n-2])
BM65(最长公共子序列(二)):dp[i][j]代表两个字符串截止到i，j位置时的最长公共子序列的长度，若i==j则dp[i-1][j-1] + 1，若i<>j则Max(dp[i-1][j], dp[i][j-1]);
想象一个二维矩阵图，当i和j位置的元素相等时，拼接到结果中，不相等时，来源于dp[i-1][j]和dp[i][j-1]中较大的一方
BM66(最长公共子串):dp[i][j]表示以i，j结尾的最长字符串的长度，若i和j位置元素相等，则dp[i][j]=dp[i-1][j-1]+1，同时判断是否更新最大值以及保存索引位供最后截取
BM67(不同路径的数目(一)):dp[i][j]表示到达i，j位置时的路径数，dp[i][j] = dp[i-1][j] + dp[i][j-1]
BM68(矩阵的最小路径和):dp[i][j]表示到达位置i，j的最小路径和，dp[i][j] = Min(dp[i-1][j], dp[i][j-1]) + matrix[i][j]
BM69(把数字翻译成字符串):dp[i]表示截至到i位置的字符串的编码方式数量，如果i位置可以直接编码，则dp[i] = dp[i-1]，如果i和i-1组合编码，则dp[i] = dp[i-2]，特别的i位置是0时，只有10，20可以编码
BM70(兑换零钱(一)):dp[i]表示兑换i元钱所需的最小张数，dp[i]默认初始化为aim+1，因为货币最小为1元，最多需要aim张，那么dp[i]=Min(dp[i], dp[i-arr[j]] + 1)
BM71(最长上升子序列(一)):dp[i]表示以i位置元素结尾的最长上升子序列的长度，若nums[0]...nums[i-1] < nums[i]，则dp[i] = Math.max(dp[0]...dp[i-1]) + 1
BM72(连续子数组的最大和):dp[i]表示以i位置元素结尾的连续子数组的最大和，dp[i] = Max(dp[i-1] + arr[i], arr[i])
BM73(最长回文字串):(1)动态规划，dp[i][j]表示i开头j结尾的字符串是否是回文串，dp[i][j] = charAt[i] == charAt[j] ? dp[i+1][j-1] : false;注意从字串长度开始遍历（2）中心扩散法
BM74(数字字符串转化为IP地址):(1)暴力枚举，总共三个点分成四段，判断长度不超过3，每段数字大小不超过255，以及排除前导0的情况(01)（2）递归+回溯
BM78(打家劫舍(一)):dp[i]表示前i家偷到的最大金额，对于第i家有偷和不偷两种选择，则dp[i]=Max(dp[i-2] + arr[i], dp[i-1])
BM79(打家劫舍(二)):状态转移方程不变，如果偷第一家则不能偷最后一家，遍历的时候无需遍历到最后一家，如果不偷第一家偷最后一家，遍历的时候需遍历到最后
BM80(买卖股票的最好时机(一)):dp[i][0]表示第i天不持有股票的最大收益，那么dp[i][0]=Max(dp[i-1][1] + prices[i], dp[i-1][0])，dp[i][1]表示第i天持有股票的最大收益，那么dp[i][1]=Max(dp[i-1][1], -prices[i])，返回最后一天不持股的最大收益
BM81(买卖股票的最好时机(二)):dp[i][0]表示第i天不持有股票的最大收益，那么dp[i][0]=Max(dp[i-1][1] + prices[i], dp[i-1][0])，dp[i][1]表示第i天持有股票的最大收益，那么dp[i][1]=Max(dp[i-1][1], dp[i-1][0]-prices[i])，返回最后一天不持股的最大收益
